# کارآگاه لوکی — پرونده: اتاق خاموش

بازی معمایی سه‌بعدی کارآگاهی در مرورگر. ساخته‌شده با **JavaScript خالص + Three.js + Vite** (بدون TypeScript، بدون React/Vue و بدون فریم‌ورک فرانت‌اند). رابط کاربری کاملاً فارسی و راست‌به‌چپ (RTL).

## اجرا

```bash
npm install
npm run dev
```

سپس مرورگر روی آدرس محلی (پیش‌فرض `http://localhost:5188`) باز می‌شود. برای ساخت نسخه نهایی:

```bash
npm run build
npm run preview
```

## کنترل‌ها

| کنش | کلید |
| --- | --- |
| حرکت | `W A S D` |
| نگاه کردن | ماوس |
| بررسی | `E` |
| حالت کارآگاه | `Space` |
| منو / توقف | `Esc` |

پس از زدن دکمه «ورود به صحنه جرم»، دوربین با قفل‌شدن نشانگر ماوس کنترل می‌شود. با `Esc` از حالت بررسی خارج می‌شوید.

## ساختار پروژه

```
src/
  main.js              نقطه ورود
  core/
    constants.js       ثابت‌ها و پیکربندی مرکزی (ابعاد، رنگ، حالت‌ها، کلیدها)
    GameState.js       ماشین حالت بازی
    Input.js           مدیریت صفحه‌کلید و قفل نشانگر ماوس
    Game.js            هماهنگ‌کننده اصلی (renderer/scene/camera/loop)
  scene/
    Materials.js       متریال و هندسه مشترک (Reuse برای Performance)
    Room.js            اتاق: کف، دیوار، پنجره، در، میز، کتابخانه، صندلی، ساعت
    Lighting.js        نورپردازی نوآر (تنها یک نور سایه‌انداز)
    CrimeScene.js      صحنه جرم اولیه: جسد، طناب، صندلی واژگون، سرنخ‌ها
  player/
    Player.js          کنترلر اول‌شخص + برخورد (AABB)
  ui/
    styles.css         استایل تاریک/نوآر/RTL
    UI.js              منو، آموزش کنترل‌ها، HUD
```

## وضعیت مراحل

- **مرحله ۱ (کامل):** معماری، اتاق، نورپردازی، کنترلر بازیکن، برخورد، صحنه جرم اولیه، منو و آموزش فارسی.
- مرحله ۲ (بعدی): سیستم تعامل با اشیا و بررسی سرنخ‌ها.
- مرحله ۳: سیستم Evidence، حالت کارآگاه، تخته شواهد.
- مرحله ۴: مظنون‌ها، دیالوگ، Timeline.
- مرحله ۵: اتهام، پایان بازی، برد/باخت.
- مرحله ۶: صدا، بهبود بصری، بهینه‌سازی، QA.

## ملاحظات Performance

- محیط کوچک و بسته؛ هندسه و متریال یک‌بار ساخته و Reuse می‌شوند.
- تنها یک نور سایه‌انداز (نور سرد پنجره) برای کنترل هزینه سایه.
- بدون Post-Processing سنگین؛ فقط مه نمایی سبک برای عمق نوآر.
- `pixelRatio` حداکثر ۲؛ `dt` حلقه محدود‌شده تا از پرش زمانی جلوگیری شود.
- همه شنونده‌های رویداد در `dispose` پاک می‌شوند (بدون نشت حافظه).

> نکته: این مرحله روی این سیستم اجرا و مرورگری تست نشده است؛ کد از نظر ساختار و منطق بازبینی شده اما اجرای نهایی با `npm run dev` روی دستگاه شما انجام می‌شود.
